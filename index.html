🎓 Final Year Project

Blind Navigator
AI Assistive Robotic Device

A robotic wheeled smart cane with a mounted camera, ESP32-based sensor fusion, and an onboard RAG-powered LLM. The visually impaired user wears earbuds and simply speaks: "What is in front of me?" — the device sees, thinks, and responds in real time.

  • Real-time multi-object detection using YOLO + ultrasonic & IR sensor fusion — 95% obstacle recognition accuracy
  • RAG-LLM pipeline: camera captures the scene, LLM interprets it, voice response delivered via earbuds — fully conversational
  • Haptic + voice-guided alerts for immediate obstacle feedback; ~30% fewer false-positive alerts vs baseline
  • ESP32 microcontroller handles edge processing + real-time sensor fusion at low latency
  • Wheeled autonomous chassis enables guided navigation in unknown environments without human assistance
